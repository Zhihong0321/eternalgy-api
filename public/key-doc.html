Connection Instructions

Base Gateway URL

HTTP Authentication Headers

Pass your API Key in either header:

x-api-key: YOUR_API_KEY
# OR
Authorization: Bearer YOUR_API_KEY
Standard HTTP Status Codes
200 OK: Successful query
201 Created: Record inserted
401 Unauthorized: Missing or invalid key
403 Forbidden: Table/action not granted
429 Rate Limit: Exceeded quota

Enforced Guardrails

  • Hard Limit Capping: Queries are capped at max 100 rows per request.
  • Statement Timeout: 5,000ms max execution time to protect database CPU.
  • Column Masking: Unapproved fields are stripped server-side.
  • Sensitive Scrubbing: Passwords, tokens, and hashes are permanently blocked.
